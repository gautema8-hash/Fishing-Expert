## 一、性能深度优化（最高优先级）

### 1.1 对象池化（消除GC卡顿的根本原因）

**问题**：v2.2版本中 Fish、Particle、Bullet 对象每次生成都 `new`，出框/死亡后直接丢弃，导致频繁的垃圾回收（GC），这是"玩一会就卡"的根本原因。

**修复**：
- **Fish对象池**：预分配20个Fish对象，`acquire()`从池中取，`release()`回收到池。鱼出框死亡后不再丢弃，而是重置状态回池复用。
- **Particle对象池**：预分配300个Particle对象，所有粒子效果（爆炸、拖尾、气泡、闪光）全部复用。
- **Bullet对象池**：炮弹对象预分配复用，发射/爆炸后回池。

### 1.2 粒子渲染优化（消除每帧createRadialGradient）

**问题**：每个粒子每帧render都调用`createRadialGradient()`创建渐变对象，这是Canvas2D中最耗性能的操作之一。300个粒子×60帧=每秒18000次渐变创建。

**修复**：
- 为8种粒子类型（default/gold/bubble/flame/scaleSpark/waterFlow/gillBubble/hitFlash）预渲染软粒子sprite到OffscreenCanvas
- 渲染时使用`drawImage()` + `globalAlpha` + `globalCompositeOperation`，零渐变创建
- ink和spark类型保持矢量绘制（数量少，不影响性能）

### 1.3 静态背景缓存

**问题**：Scene.js每帧全量重绘所有背景元素（远景山脉、龙宫轮廓、珊瑚柱、渐变天空），大量重复绘制。

**修复**：
- 将静态背景层（远山轮廓、龙宫塔楼、渐变底色、珊瑚柱底座）预渲染到`_staticBgCanvas`离屏画布
- 每帧只`drawImage`一次静态缓存，动态元素（海草摆动、宫灯呼吸、远景鱼群）仍每帧重绘
- resize时自动失效缓存并重建

### 1.4 游戏循环保护

- **visibilitychange自动暂停**：标签页切换到后台时自动暂停游戏，切回时恢复，避免后台累积大量update
- **accumulator上限保护**：固定时间步长的累积器最多累积5帧，防止标签页切回后一次性追赶数百帧导致"更新风暴"
- **FPS自适应鱼数**：FPS<45时鱼数降低20%，FPS<30时降低40%，保证流畅度优先

### 1.5 渲染排序优化

**问题**：FishSchool.render()每帧执行`[...this.fishes].sort()`，创建新数组并排序。

**修复**：
- 按depth维护far/mid/near三个数组，鱼生成/回收时自动归入对应组
- render时依次遍历三组绘制，零排序开销
- 同时消除`getAllAliveFish()`每帧创建新数组的问题，使用dirty标记的缓存数组

### 1.6 VerletSystem复用

**问题**：每条鱼每次init都`new VerletSystem()`创建物理系统，鱼对象池化后仍反复创建。

**修复**：Fish对象首次init时创建VerletSystem，后续reset/init时复用并重置节点，不再重新new。

### 性能优化预期效果

| 指标 | v2.2 | v3.0 | 提升 |
|------|------|------|------|
| 对象创建/秒 | ~500个 | ~20个 | 25倍减少 |
| 渐变创建/秒 | ~18000次 | ~100次 | 180倍减少 |
| 背景绘制/帧 | ~200次路径 | ~1次drawImage | 200倍减少 |
| 长时间运行 | 5分钟后明显卡顿 | 稳定60FPS | 根本解决 |

## 二、AI超逼真美术素材（全透明背景）

### 2.1 鱼类图片（30种，全部1024×1024 RGBA透明）

**原有鱼类重新生成（13种）**：彩色金鱼、小银鱼、灵龟、蝠鲼、幻彩水母、珊瑚海马、深海灯笼鱼、黑龙、黄金龙鱼、东海龙王(→中国金龙)、雷电鳗、幽灵鱼、分裂水母

**新增鱼类（17种）**：
- 小型鱼：小丑鱼、孔雀鱼、斑马鱼、霓虹灯鱼（发光）
- 中型鱼：河豚、章鱼、鱿鱼、七彩神仙鱼、龙虾、螃蟹、海星
- 大型鱼：鲨鱼、旗鱼、金枪鱼、石斑鱼
- 海洋哺乳动物：海豚（稀有）、鲸鱼（极稀有）

**技术处理**：
- AI生成后通过Python/PIL脚本批量去除白色背景，添加真正的alpha透明通道
- 边缘feather=30平滑过渡，避免生硬锯齿
- 所有PNG确认为RGBA模式，角落无残留不透明像素
- 灯笼鱼/电鳗的发光效果自然保留

## 四、金币亿级单位

### 4.1 格式化工具
新增`Utils.formatCoin(amount)`方法：
- < 10,000：直接显示（如 9,999）
- 1万 ~ 1亿：显示 "X.XX万"（如 1.23万）
- 1亿 ~ 1万亿：显示 "X.XX亿"（如 12.35亿）
- ≥ 1万亿：显示 "X.XX万亿"（如 1.23万亿）
- 保留2位小数，自动去掉末尾多余的0

### 4.2 全局替换
所有金币显示位置已替换为formatCoin：
- 顶部状态栏金币显示
- 关卡完成/转盘抽奖 toast 消息
- 商城礼包/订阅价格
- 任务奖励/统计面板
- 成就/邮件/好友/公会BOSS奖励
- 离线收益/回归礼包/签到奖励
- 炮台升级/宠物系统
- EconomySystem.getDisplayCoins()

### 4.3 初始金币
新玩家初始金币调整为 **1亿（100,000,000）**，让玩家立即体验亿级单位。老玩家存档因`_deepMerge`不覆盖已有coins，保持不变。

## 五、鱼群生态丰富度

### 5.1 种类多样性算法升级
- 最近生成种类记忆窗口：4 → 8
- 重复种类重抽概率：0.6 → 0.8
- 新增`_countOnScreenTypes()`同屏种类计数
- 按现存量加权选择：未出现的种类×3权重、单条×1.6、≥4条×0.4
- 同屏种类<5且鱼数≥10时，强制从未出现种类中挑选
- 确保同屏同时有8-10种不同鱼类

### 5.2 游动路径多样化
新鱼配置覆盖全部6种路径类型：
- linear（直线）：小银鱼、金枪鱼
- sine（正弦）：金鱼、蝠鲼、黑龙、雷电鳗、鲨鱼
- circle（环形）：黄金龙鱼、海豚
- float（漂浮）：水母、分裂水母、鲸鱼
- erratic（不规则）：海马、幽灵鱼、章鱼
- random（随机）：灵龟、灯笼鱼、龙虾、螃蟹、海星

### 5.3 鱼群行为
- 小型鱼结群（5-20条），中型鱼单独或小群，大型鱼单独
- 珍稀鱼（海豚weight=3、鲸鱼weight=1）稀有出现，增加惊喜感
- 海洋生物（海龟、海豚、鲸鱼）偶尔出现，丰富生态

## 八、技术亮点

1. **对象池三件套**：Fish/Particle/Bullet全部池化，从根本上消除GC卡顿
2. **粒子sprite预渲染**：8种软粒子预渲染到OffscreenCanvas，消除每帧18000次渐变创建
3. **静态背景缓存**：远景/龙宫/珊瑚预渲染，每帧从200次路径绘制降为1次drawImage
4. **AI美术全透明**：Python/PIL批量去背景+feather边缘平滑，30种鱼零黑框
5. **BOSS图片+特效混合**：AI金龙图片为主体，程序化外发光/呼吸光/龙鳞闪光叠加
6. **多样性加权算法**：同屏种类计数+现存量加权，确保生态丰富不重复
7. **亿级单位格式化**：万/亿/万亿三级自动切换，全局统一显示
