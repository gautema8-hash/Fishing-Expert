## 4. P0 - 紧急修复项

### 4.1 新手引导弹窗修复

**问题**: 点击✕或"跳过引导"后弹窗仍然存在，可能存在多个引导层叠加。

**根因分析**:
- TutorialSystem可能创建了多个overlay实例
- 关闭事件未正确移除DOM元素
- 状态机状态未正确同步

**修复方案**:

```javascript
// 1. 确保单例模式
class TutorialSystem {
    static instance = null;
    
    constructor() {
        if (TutorialSystem.instance) return TutorialSystem.instance;
        TutorialSystem.instance = this;
        this.overlay = null;
        this.isActive = false;
    }
    
    // 2. 关闭时彻底清理
    close() {
        this.isActive = false;
        if (this.overlay) {
            this.overlay.remove();
            this.overlay = null;
        }
        document.body.style.overflow = '';
        this.saveProgress();
    }
    
    // 3. 防止重复创建
    show() {
        if (this.isActive || this.overlay) return;
        this.isActive = true;
        this.createOverlay();
    }
}
```

**验证标准**:
- [ ] 点击✕后弹窗完全消失
- [ ] 点击"跳过引导"后弹窗完全消失
- [ ] 不会出现多个引导层叠加
- [ ] 跳过状态正确保存，下次进入不重复显示

### 4.2 FPS监控面板实现

**问题**: 设置中开启FPS显示后画面无变化，renderer.fps为undefined。

**修复方案**:

```javascript
// Renderer.js中添加FPS计算
class Renderer {
    constructor() {
        this.fps = 60;
        this.frameCount = 0;
        this.fpsUpdateTime = 0;
        this.fpsHistory = [];
    }
    
    update(deltaTime) {
        this.frameCount++;
        const now = performance.now();
        
        if (now - this.fpsUpdateTime >= 1000) {
            this.fps = Math.round(this.frameCount * 1000 / (now - this.fpsUpdateTime));
            this.frameCount = 0;
            this.fpsUpdateTime = now;
            this.fpsHistory.push(this.fps);
            if (this.fpsHistory.length > 60) this.fpsHistory.shift();
        }
    }
    
    renderFPS(ctx) {
        if (!this.showFPS) return;
        ctx.save();
        ctx.font = '14px monospace';
        ctx.fillStyle = this.fps >= 50 ? '#00ff00' : this.fps >= 30 ? '#ffff00' : '#ff0000';
        ctx.fillText(`FPS: ${this.fps}`, 10, 25);
        ctx.fillText(`帧: ${this.frameCount}`, 10, 45);
        ctx.restore();
    }
}
```

**验证标准**:
- [ ] 设置中开启FPS后左上角显示实时FPS
- [ ] FPS数值每秒更新
- [ ] 低帧率时颜色变红警告
- [ ] 关闭设置后FPS显示消失

**预计工时**: 4人时  
**风险**: 低  
**依赖**: 无

## 5. P1 - 性能优化

### 5.1 渲染性能优化

#### 5.1.1 离屏Canvas缓存静态背景

**现状**: 每帧重绘龙宫背景、珊瑚、海草等静态元素。

**优化**: 将静态背景预渲染到离屏Canvas，每帧直接drawImage。

```javascript
class Scene {
    init() {
        this.bgCanvas = document.createElement('canvas');
        this.bgCanvas.width = this.width;
        this.bgCanvas.height = this.height;
        this.bgCtx = this.bgCanvas.getContext('2d');
        this.renderStaticBackground(this.bgCtx);
    }
    
    render(ctx) {
        ctx.drawImage(this.bgCanvas, 0, 0); // O(1) 替代 O(n) 重绘
    }
}
```

**预期收益**: 背景渲染耗时降低80%，整体帧率提升15-20%

#### 5.1.2 鱼群视锥剔除

**现状**: 20条鱼全部参与渲染和更新，包括屏幕外的鱼。

**优化**: 只更新和渲染视口内的鱼，屏幕外的鱼只做位置更新不渲染。

```javascript
class FishManager {
    update(deltaTime) {
        this.fishes.forEach(fish => {
            fish.update(deltaTime); // 全部更新位置
            fish.visible = fish.x > -100 && fish.x < this.width + 100 &&
                           fish.y > -100 && fish.y < this.height + 100;
        });
    }
    
    render(ctx) {
        this.fishes.forEach(fish => {
            if (fish.visible) fish.render(ctx); // 只渲染可见的
        });
    }
}
```

**预期收益**: 鱼群渲染数量平均减少30%，帧率提升10%

#### 5.1.3 粒子系统上限控制

**现状**: 粒子数量无上限，暴击或BOSS死亡时可能产生数百粒子导致卡顿。

**优化**: 设置粒子池上限（建议200个），超出时复用最旧的粒子。

```javascript
class ParticleSystem {
    constructor() {
        this.maxParticles = 200;
        this.pool = new ObjectPool(Particle, this.maxParticles);
    }
    
    emit(x, y, count) {
        for (let i = 0; i < count; i++) {
            if (this.activeParticles.length >= this.maxParticles) {
                const oldest = this.activeParticles.shift();
                oldest.reset(x, y);
                this.activeParticles.push(oldest);
            } else {
                const p = this.pool.acquire();
                p.init(x, y);
                this.activeParticles.push(p);
            }
        }
    }
}
```

**预期收益**: 极端场景帧率稳定在30FPS以上，避免卡顿

### 5.2 内存优化

#### 5.2.1 图片资源WebP格式 + 懒加载

### 5.3 低端机自动降级

**实现方案**:

```javascript
class PerformanceManager {
    constructor() {
        this.level = 'high'; // high / medium / low
        this.fpsHistory = [];
    }
    
    monitor() {
        setInterval(() => {
            const avgFps = this.fpsHistory.reduce((a,b) => a+b, 0) / this.fpsHistory.length;
            
            if (avgFps < 25 && this.level !== 'low') {
                this.level = 'low';
                this.applyLowSettings();
            } else if (avgFps < 40 && this.level === 'high') {
                this.level = 'medium';
                this.applyMediumSettings();
            }
        }, 5000);
    }
    
    applyLowSettings() {
        this.game.particleSystem.maxParticles = 50;
        this.game.caustics.enabled = false;
        this.game.volumetricFog.enabled = false;
        this.game.fishManager.maxFish = 10;
        this.game.renderer.quality = 'low';
    }
}
```

**预期收益**: 低端机（3年前安卓机型）可稳定30FPS运行

### 6.2 金币数字动效优化

**现状**: 金币变化时直接跳变，无过渡动画。

**优化**: 实现数字滚动动画，击杀获得金币时数字从当前值滚动到目标值。

```javascript
class CoinDisplay {
    animateTo(target, duration = 500) {
        const start = this.current;
        const startTime = performance.now();
        
        const update = () => {
            const elapsed = performance.now() - startTime;
            const progress = Math.min(elapsed / duration, 1);
            const eased = 1 - Math.pow(1 - progress, 3); // easeOutCubic
            this.current = Math.floor(start + (target - start) * eased);
            this.element.textContent = this.formatNumber(this.current);
            
            if (progress < 1) requestAnimationFrame(update);
        };
        requestAnimationFrame(update);
    }
}
```
