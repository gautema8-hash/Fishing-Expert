## 一、项目概述

### 1.1 项目定位
商用级休闲捕鱼 H5 网页游戏，国风东海龙宫主题，暗调深海墨蓝主色调，青金琉璃流光 + 金色龙纹粒子高光视觉体系。移动端优先，兼容 PC 浏览器，可上线运营。

### 1.2 核心目标
- 交互逻辑完整可玩（发射 → 命中 → 捕获 → 金币结算 → 关卡推进）
- 商用级高质量 UI（琉璃磨砂玻璃面板、鎏金发光边框、青金渐变字体）
- 炫酷特效（粒子爆炸、水波纹、焦散光影、体积雾、骨骼动画鱼群）
- 可运营工程架构（配置驱动、对象池、模块化、性能自适应）

### 1.3 技术选型
| 层级 | 技术方案 |
|------|----------|
| 渲染 | HTML5 Canvas 2D（主），WebGL 可选加速 |
| 语言 | 原生 JavaScript ES6+（无框架依赖，零构建开箱即用） |
| 样式 | CSS3 + CSS 变量主题系统 |
| 音频 | Web Audio API |
| 存储 | localStorage（本地存档） |
| PWA | Service Worker + manifest.json |
| 适配 | viewport + rem + 安全区 env() |

## 四、风险管理

| 风险 | 影响 | 概率 | 应对策略 |
|------|------|------|----------|
| Canvas 粒子数量过多导致移动端卡顿 | 高 | 中 | 对象池 + 性能自适应降级 + 粒子上限 |
| 骨骼动画鱼群渲染开销大 | 中 | 中 | 简化骨骼段数（5-8 段）、远景鱼降级 |
| 音效资源加载慢 | 中 | 低 | Web Audio 程序化生成 + 懒加载 |
| 移动端浏览器兼容性差异 | 中 | 中 | 特性检测 + 降级方案、主流浏览器测试 |
| 金币经济失衡导致玩家过快破产 | 高 | 中 | 期望收益模型校准 + 新手保护期 + 低保机制 |
| 需求范围过大导致延期 | 高 | 高 | 按里程碑交付，P0 优先，P2 可后续迭代 |

## 五、验收标准

### 5.1 功能验收
- [ ] 游戏可正常启动，无控制台报错
- [ ] 点击/触摸可发射炮弹，炮弹可命中鱼类
- [ ] 击杀鱼类获得对应金币，金币数值实时更新
- [ ] 炮台倍率 1-10 可切换，消耗对应金币
- [ ] 金币不足时弹出充值弹窗
- [ ] 关卡可推进，难度递增
- [ ] BOSS 可出场、可击杀、掉落大量金币
- [ ] 暴击可随机触发，有视觉反馈和双倍奖励
- [ ] 道具可使用（锁定、狂暴）
- [ ] 所有弹窗可正常打开关闭
- [ ] 音效可开关，背景音乐可播放

### 5.2 性能验收
- [ ] 中端移动端 FPS ≥ 30
- [ ] 低端移动端 FPS ≥ 20（降级后）
- [ ] 无明显内存泄漏（长时间运行内存稳定）
- [ ] 首屏加载时间 ≤ 3s（4G 网络）

### 5.3 视觉验收
- [ ] 整体国风东海龙宫风格统一
- [ ] 暗调深海墨蓝主色调，青金琉璃高光
- [ ] UI 为琉璃磨砂玻璃面板 + 鎏金发光边框
- [ ] 鱼类有骨骼动画（身体摆动、鱼鳍扇动）
- [ ] 有粒子爆炸、水波纹、焦散光影特效
- [ ] 多层视差营造空间纵深感
- [ ] 无廉价卡通土味画风

### 5.4 合规验收
- [ ] 隐私政策弹窗首次启动展示
- [ ] 游戏内货币明确标注为虚拟道具
- [ ] 无赌博元素、无真实货币兑换
- [ ] 抽奖类玩法明示概率
- [ ] 防沉迷提示到位
