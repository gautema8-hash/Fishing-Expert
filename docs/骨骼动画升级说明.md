# 骨骼动画系统升级说明

## 升级概述

本次升级为捕鱼达人游戏引入了**轻量级骨骼动画系统**，实现真实的海底生物运动效果。核心改变：鱼类渲染从"静态图片整体平移"升级为"图片切片+骨骼驱动变形"，鱼儿身体可以真实弯曲摆动，乌龟四肢交替划水，章鱼触手波浪摆动，水母伞盖收缩舒张，BOSS金龙龙身蜿蜒扭动。

## 核心原理

### 图片切片骨骼变形

将整鱼图片沿身体长轴切成 N 个垂直条带（默认6-12条，根据鱼的大小动态调整），每个条带绑定一节脊椎骨骼。渲染时从尾部向头部依次绘制，每条带按对应骨骼的世界坐标和角度独立变换，条带间重叠4像素掩盖接缝。

```
整鱼图片 → 垂直切片 → 骨骼驱动每片位置/角度 → 连续弯曲的鱼身
```

### 脊椎S形波动

每节脊椎的局部角度 = `sin(time * frequency - segmentIndex * phase) * amplitude * amplitudeRamp`，其中 amplitudeRamp 从头部0.3线性增长到尾部1.5，形成头小尾大的自然摆幅。世界角度通过前向运动学（父骨骼角度+局部角度）累积。

### 生物类型路由

Fish.js 通过 `_detectCreatureType()` 自动识别生物类型：
- **fish/dragon** → FishSkeleton + SkeletalFishRenderer（图片切片变形）
- **turtle** → TurtleRenderer（壳+四腿划水+头伸缩）
- **octopus** → OctopusRenderer（外套膜+8触手波动）
- **jellyfish** → JellyfishRenderer（伞盖收缩+触手飘动）
- **crustacean/echinoderm** → 静态图片（肢体结构特殊，暂不骨骼化）

## 性能特性

### 动态质量调整

- **小鱼少切片**：size<28 → 6节，size<40 → 7节，size<70 → 8节，大鱼用配置值
- **远景降级**：depth=far 且 size<80 的鱼使用静态图片（半透明缩小，骨骼效果不明显）
- **极小图降级**：size<24 的鱼使用静态图片
- **小鱼无鳍叠加**：size<35 的鱼跳过程序化胸鳍渲染

### 零分配热路径

- Bone.computeWorld() 直接写入 wx/wy/wAngle 公共字段，不创建临时对象
- Skeleton.update() 按根→叶迭代计算，无递归
- 切片画布按 imageSrc+sliceCount 缓存，同种鱼共享
- 切片→骨骼索引用 Int8Array 缓存，消除每帧 Math.round

### 三级降级

1. 骨骼切片动画（首选）
2. 静态图片渲染（骨骼失败时）
3. 程序化绘制（图片加载失败时）

## 动画状态

继承原有7种动画状态机（idle/swim/fast/turn/escape/hurt/dying），每种状态有独立的频率/幅度/弯曲度倍率。速度影响动画频率（speedInfluence=0.5），转向影响身体弯曲度（turnBend）。

## 兼容性

- **公开接口不变**：Fish 的 init/update/render/hit/getCollisionRadius/isBoss/isAlive 签名完全保持
- **原有功能保留**：捕获、金币、技能、鱼群、AI行为、景深、发光、受击闪烁、死亡翻白等全部保留
- **程序化绘制保留**：无图片时仍使用原有的程序化骨骼绘制（菲涅尔光、鱼鳞纹理、Verlet鱼鳍）
- **对象池兼容**：骨骼实例通过 configure() 复用，适配 Fish 的对象池机制

## 已知限制

1. **螃蟹/龙虾/海星等**：肢体结构特殊（非鱼类脊椎），暂使用静态图片渲染
2. **蝠鲼/黄貂鱼**：宽扁体形，垂直切片效果有限，仍使用骨骼动画但弯曲度较小
3. **图片朝向假设**：所有鱼类图片假设头朝右（+X方向），与项目现有约定一致
4. **横屏体验**：游戏设计为横屏，竖屏模式下显示"请横屏"提示

## 扩展指南

### 新增鱼种骨骼动画

在 fishConfig.js 中配置 `spineSegments`（建议8-12）和 `imageScale`（图片显示宽度/鱼尺寸的比值）即可自动获得骨骼动画，无需额外代码。

### 新增特殊生物渲染器

1. 在 animation/ 目录创建 XxxRenderer.js，导出单例 `xxxRenderer`
2. 实现 `render(ctx, fish, image) -> boolean` 方法
3. 在 Fish.js 的 import 中添加该渲染器
4. 在 `_detectCreatureType()` 中添加类型识别
5. 在 render() 的图片路径中添加路由分支

### 调整动画参数

在 fishConfig.js 的 `boneAnimation` 中调整：
- `bodyWaveFrequency`：身体摆动频率（默认3）
- `bodyWaveAmplitude`：身体摆动幅度弧度（默认0.15）
- `tailFrequency/tailAmplitude`：尾鳍参数
- `finFrequency/finAmplitude`：胸鳍参数
- `headAmpScale/tailAmpScale`：头尾摆幅比例

在 `animStates` 中调整各状态的倍率。
