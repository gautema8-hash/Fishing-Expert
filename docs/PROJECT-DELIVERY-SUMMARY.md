## 一、项目概述

### 1.1 项目信息
| 项目 | 内容 |
|------|------|
| 项目名称 | 捕鱼达人·东海龙宫 |
| 项目类型 | 商用休闲捕鱼H5网页游戏 |
| 美术风格 | 国风东海龙宫主题，暗调深海墨蓝 |
| 技术栈 | 前端：原生JS + Canvas + HTML5；后端：Spring Boot 2.7 + MyBatis-Plus + PostgreSQL + Redis |
| 交付日期 | 2026年9月 |
| 项目状态 | 已完成交付 |

### 1.2 项目目标
- 开发一款商用级高品质捕鱼H5游戏
- 国风东海龙宫主题，视觉炫酷
- 完整游戏逻辑，可上线运营
- 移动端优先，兼容PC浏览器
- 完整后端服务，支持商业化运营
