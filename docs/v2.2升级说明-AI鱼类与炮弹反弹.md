# v2.2 升级说明 — AI逼真鱼类 + 四面八方鱼群 + 炮弹边界反弹

## 升级概述

v2.2 版本对捕鱼游戏的视觉表现和游戏体验进行了三大核心升级：

1. **AI生成逼真鱼类图片**：13种鱼类全部使用AI生成的3D超逼真图片，替代原有的纯程序化绘制
2. **鱼群四面八方生成**：鱼从屏幕上下左右四个方向随机进入，游出屏幕后自动消失，形成真实的海洋生态感
3. **炮弹边界反弹**：炮弹碰到屏幕边缘时反弹（入射角=反射角），最多反弹3次后消失，未击中的炮弹不再浪费

### 图片渲染机制

- **图片渲染**：鱼类优先使用AI图片渲染，支持缩放、旋转、透明度、受击闪白
- **游动摆动**：图片渲染时叠加sin波微小旋转，模拟鱼身摆动效果

### Fallback降级机制

图片加载失败、图片不存在或任何异常时，自动降级为原有的程序化骨骼绘制（菲涅尔光影+Verlet鱼鳍物理+鱼鳞纹理），游戏不会白屏或报错。

## 二、鱼群四面八方生成

### 生成方向

鱼可以从屏幕四个方向随机进入：

| 方向 | 出生坐标 | 初始朝向 |
|------|----------|----------|
| 左侧 (left) | x=-50, y=随机 | 向右 (0°) |
| 右侧 (right) | x=width+50, y=随机 | 向左 (180°) |
| 顶部 (top) | x=随机, y=-50 | 向下 (90°) |
| 底部 (bottom) | x=随机, y=height+50 | 向上 (-90°) |

### 生成策略

- **随机间隔**：生成间隔从固定2秒改为0.8~2.5秒随机，避免规律性
- **批量生成**：每次生成1~3条鱼，种类尽量多样
- **种类多样性**：记录最近生成的4种鱼，降低重复概率（60%概率重抽）
- **速度随机化**：每种鱼有speedRange配置，速度在范围内随机
- **方向偏好**：每种鱼可配置spawnDirections偏好方向，小鱼全方向，大鱼偏好左右，BOSS偏好顶部

### 鱼群生成

- 结群鱼类（金鱼、银鱼、水母、海马等）按35%概率生成鱼群
- 鱼群同样支持四方向生成
- 鱼群大小按配置的schoolSize范围随机

### 出框消失

- 鱼游出屏幕边界100px后，自动标记为dead并从fishes数组移除
- 不再像旧版本那样把鱼拉回屏幕内
- 鱼群中心出框后鱼群自动解散

### BOSS出场

- BOSS从顶部或右侧随机入场（增加出场感）
- 保持原有的2秒出场预警机制
- BOSS驱散小鱼行为不变

## 三、炮弹边界反弹

### 反弹机制

- 炮弹碰到屏幕四个边缘时反弹（入射角=反射角）
- 反弹时炮弹位置贴齐边界，速度分量取反
- 反弹后速度衰减为原来的0.9倍
- 反弹后重新计算炮弹朝向角

### 反弹限制

- 最多反弹3次，超过后炮弹自动消失
- 反弹计数在炮弹初始化时重置为0
- 炮弹命中鱼后正常爆炸消失（不消耗反弹次数）

### 视觉反馈

- 反弹时炮弹有缩放脉冲效果（放大1.3倍后逐渐恢复）
- 脉冲在5秒内衰减完毕
- `_justBounced`标志可供外部系统生成水花粒子

### 配置项

```js
// gameConfig.js
bullet: {
    maxBounces: 3,           // 最大反弹次数
    bounceSpeedDecay: 0.9,   // 反弹速度衰减倍率
}

// fishConfig.js
bulletBounce: {
    maxBounces: 3,
    speedDecay: 0.9,
    bounceScalePulse: 1.3,
    bounceParticleCount: 8,
}
```

## 七、后续优化建议

1. **水花粒子**：可在BulletManager中检测`_justBounced`标志，生成水花粒子效果
2. **鱼类动画**：可考虑使用精灵图序列帧替代静态图片，实现更生动的游动动画
3. **图片压缩**：可将PNG转换为WebP格式，减少约30%文件大小
4. **自适应画质**：低画质设备可自动降级为程序化绘制，减少显存占用
