## 二、严重问题（🔴 必须修复）

### Bug #1：金币亿级单位完全未实现

**严重程度**：🔴 高  
**影响范围**：全局金币显示

**问题描述**：
- v3.0承诺实现`Utils.formatCoin()`万/亿/万亿三级自动切换，但实际`Utils.formatCoin`不存在
- 设置`game.economy.coins = 150000000`后，UI仍显示"3.2万"，不更新
- 新玩家初始金币仍是32010，不是承诺的1亿
- 所有金币显示位置仍使用旧的格式化逻辑

**复现步骤**：
1. 打开游戏，查看顶部金币显示"3.2万"
2. 控制台执行`window.__game.economy.coins = 150000000`
3. 金币显示无变化，仍为"3.2万"
4. 控制台执行`typeof Utils.formatCoin`返回"undefined"

**预期结果**：
- 150000000应显示为"1.50亿"
- 初始金币应为1亿
- 全局统一使用亿级单位

**修复建议**：
- 在`Utils`类中添加`formatCoin(coins)`方法
- 修改`Economy.updateUI()`使用新格式化方法
- 修改所有弹窗中的金币显示
- 修改初始金币配置为1亿

---

### Bug #2：部分鱼类图片仍有黑框/黑背景

**严重程度**：🔴 高  
**影响范围**：视觉品质

**问题描述**：
- v3.0承诺"全透明零黑框"，但实际多种鱼仍有黑色方块背景
- 受影响鱼类：金鱼、孔雀鱼、蝠鲼、小丑鱼等
- 黑框在深色背景上非常明显，严重影响商业级品质
- BOSS中国金龙没有黑框（效果好），但普通鱼有

**截图证据**：
- 左下角孔雀鱼：明显黑色方块背景
- 左侧金鱼：黑色背景
- 左下角蝠鲼：黑色边缘

**可能原因**：
- AI生成的图片本身不是透明背景
- Python/PIL去白底处理不彻底，边缘残留
- 部分鱼使用了旧的未处理图片

**修复建议**：
- 重新生成所有鱼类图片，prompt明确要求"transparent background, PNG, alpha channel"
- 使用专业去背景工具（如remove.bg API）处理
- 逐张检查图片透明度，确保边缘无残留
-  Fish.js渲染时添加`globalCompositeOperation`优化

### Bug #4：炮弹发射后立即消失，无法测试反弹

**严重程度**：🟡 中  
**影响范围**：核心玩法

**问题描述**：
- 发射5发炮弹后，`bulletManager.bullets.length = 0`
- 炮弹可能发射后立即消失，或炮弹数组名不正确
- 无法验证v2.2的炮弹边界反弹功能
- 金币正常消耗（32010→32000），说明发射逻辑执行了

**可能原因**：
- `bulletManager.bullets`数组名不对，可能是`_bullets`或其他
- 炮弹速度过快，瞬间飞出屏幕后消失
- 反弹逻辑有bug，炮弹碰边界后直接销毁

**修复建议**：
- 检查`BulletManager.js`中炮弹数组的实际名称
- 降低炮弹初始速度，便于观察反弹
- 添加炮弹调试显示（轨迹线）
- 验证`Bullet.update()`中的边界反弹逻辑
