## 六、发现的Bug与问题

### 6.1 严重Bug（需立即修复）

#### Bug #1：每日任务弹窗内容为空
- **严重程度**：🔴 高
- **复现步骤**：打开游戏 → 点击底部任务按钮 → 任务弹窗只有标题"每日任务"，内容区域空白
- **预期结果**：显示每日任务列表（如"捕获10条鱼"、"发射100发炮弹"等），带进度条和领取按钮
- **实际结果**：内容区域完全空白，无任何任务项
- **可能原因**：
  1. `_fillTask`方法未正确渲染任务数据
  2. 任务系统未初始化或任务数据为空
  3. 任务配置缺失
- **影响**：玩家无法查看和完成每日任务，影响留存和活跃度
- **建议修复**：检查`UIManager.js`的`_fillTask`方法，确认任务数据来源和渲染逻辑

### 6.2 中等问题（需优化）

#### Issue #1：弹窗关闭后游戏保持暂停状态
- **严重程度**：🟡 中
- **复现步骤**：打开任意弹窗（如商城/设置）→ 关闭弹窗 → 游戏状态仍为paused
- **预期结果**：关闭弹窗后游戏自动恢复playing状态
- **实际结果**：游戏保持paused，鱼群停止生成，需手动调用resume()
- **可能原因**：弹窗open时设置paused=true，但close时未设置paused=false
- **影响**：玩家关闭弹窗后发现鱼群消失，误以为游戏卡住
- **建议修复**：在`closePopup`方法中添加游戏恢复逻辑

#### Issue #2：排行榜为模拟数据
- **严重程度**：🟡 中
- **详情**：排行榜显示"龙宫至尊9999万"、"东海龙王8888万"等固定模拟数据
- **建议**：前端本地游戏可接受模拟数据，但建议接入后端真实排行榜API

#### Issue #3：暂停方法名不统一
- **严重程度**：🟢 低
- **详情**：`game.pause()`不存在，实际方法可能是`_pause()`或其他命名
- **建议**：统一公开API命名，添加`pause()`/`resume()`公开方法

### 6.3 轻微问题（可选优化）

#### Issue #4：粒子系统属性名不统一
- **详情**：`particleSystem.particles`不存在，实际属性名可能不同
- **建议**：统一粒子数组命名，方便调试和监控

#### Issue #5：横屏检测影响PC测试
- **详情**：PC浏览器竖屏时显示"请横屏体验游戏"，需手动绕过
- **建议**：PC端可默认横屏显示，或添加"继续游戏"按钮
