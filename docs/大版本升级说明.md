## 二、核心升级详解

### 2.1 鱼儿伪3D光影渲染

#### 菲涅尔边缘光（Fresnel Effect）
- **实现原理**: `F(θ) = F0 + (1-F0)(1-cosθ)^5`，基于鱼身骨骼段角度计算掠射角反射强度
- **视觉效果**: 鱼身侧面（掠射角）呈现明亮边缘光晕，鱼身正面保持本色透光感
- **鱼种差异**: 金龙鱼/龙王 F0=0.3（强反射），普通鱼 F0=0.08-0.2（弱反射）
- **配置项**: `fishConfig.types[鱼id].fresnelIntensity`

#### 方向光模拟（顶部高光+底部阴影）
- **实现原理**: 鱼身每段使用线性渐变，顶部用accentColor提亮（模拟水面入射阳光），底部用finColor压暗
- **俯仰联动**: 高光强度随鱼的俯仰角度（`_pitch`）动态变化
- **视觉效果**: 鱼身上方亮、下方暗，形成立体体积感

#### 鱼鳞纹理程序化生成
- **实现原理**: 预渲染鱼鳞纹理到OffscreenCanvas（半圆阵列），Fish类静态缓存，4种鳞型
- **纹理类型**:
  - `cycloid`（圆鳞）: 光滑半圆阵列，普通鱼
  - `ctenoid`（栉鳞）: 带细齿边缘，硬骨鱼
  - `ganoid`（硬鳞）: 菱形厚鳞，远古鱼类
  - `dragon`（龙鳞）: 华丽龙鳞纹，金龙鱼/龙王
- **变形映射**: 按鱼身骨骼段角度旋转clip后pattern平铺，随鱼身弯曲变形
- **微高光闪烁**: `emitScaleSpark()` 方法自动随机触发鱼鳞闪光粒子

#### 鱼鳍半透明效果
- **透明度**: 胸鳍/背鳍/尾鳍 globalAlpha 0.65-0.72
- **边缘渐变**: 根部实、边缘透的线性/径向渐变，模拟薄膜透光
- **飘动变色**: 鱼鳍颜色深浅随摆动相位变化
- **光线透射**: 鱼鳍边缘加亮，模拟光线穿透薄膜效果

### 2.2 骨骼动画升级

#### 脊椎骨骼数量提升
- **升级前**: 3-8节（配置驱动，小鱼仅4节）
- **升级后**: 最小8节，小鱼8节，中鱼9-10节，大鱼11-12节，龙王/金龙鱼12节
- **摆幅梯度**: 头部0.3x → 躯干1.0x → 尾部1.5x 线性ramp，实现自然S形波浪
- **配置项**: `fishConfig.types[鱼id].spineSegments`

#### 独立鱼鳍骨骼
- **胸鳍（左右）**: 各2-3节独立骨骼，独立扇动频率和相位，可反向扇动（转弯时）
- **背鳍**: 多节骨骼，随水流飘动，每节独立相位
- **尾鳍**: 左右两叶独立骨骼，大幅摆动产生推进力
- **腹鳍/臀鳍**: 微调平衡，小幅摆动

#### 7种动画状态机
| 状态 | 触发条件 | 动画表现 |
|------|---------|---------|
| `idle`（巡游） | 速度 < baseSpeed×0.5 | 缓慢S形摆动（频率0.5x），胸鳍轻扇 |
| `swim`（游动） | 正常速度 | 正常频率（1.0x），尾鳍中幅摆动 |
| `fast`（加速） | 速度 > baseSpeed×1.3 | 尾鳍大幅快速摆动（频率1.8x），身体弯曲度1.5x |
| `turn`（转弯） | 方向变化 > 6rad/s | 身体侧向弯曲，胸鳍反向扇动 |
| `escape`（逃跑） | 躲避炮弹中（`_dodging`） | 极速摆动（频率2.5x），身体呈C形弹射 |
| `hurt`（受击） | 受击后0.3秒内 | 身体抽搐，短暂僵直，颜色变白 |
| `dying`（死亡） | 血量归零 | 翻转上浮（肚皮朝上），鱼鳍下垂，透明度降低 |

- **状态优先级**: dying > hurt > escape > fast > turn > idle > swim
- **配置项**: `fishConfig.animStates`（各状态频率/幅度倍率表）、`fishConfig.stateRules`（切换阈值）

### 2.3 Verlet物理模拟（鱼鳍飘动）

#### 新建模块 `VerletPhysics.js`
- **积分公式**: `x(t+Δt) = x + (x - xPrev) × damping + force × dt²`
- **约束求解**: 3次迭代，保持骨骼节点距离约束
- **阻尼系数**: 0.85（模拟水阻力）
- **刚度**: 鱼身0.9，鱼鳍0.3
- **质量**: 鱼头1.5（重），鱼尾0.5（轻）
- **水流力**: 全局洋流 + 局部正弦扰动

#### 应用部位
- 胸鳍边缘节点（每侧3-5个节点）
- 背鳍边缘节点（5-8个节点）
- 尾鳍边缘节点（每叶3-5个节点）
- 每帧将根节点吸附到骨骼锚点，施加反向阻力+正弦扰动后步进
- 鳍片轮廓直接读取物理节点位置绘制，实现真实飘动效果

### 2.4 后处理效果

#### Bloom泛光效果（Renderer.js）
- **实现架构**: 新增第6层 `glow` 发光采集层（zIndex 5，fx与ui之间）
- **工作流程**:
  1. 发光物体（发光鱼/金币/炮弹/暴击特效）在绘制主画面同时，用纯色绘制到glow层
  2. `_postProcess()` 在 `endFrame()` 中执行：glow层缩小到1/4分辨率采集亮部
  3. 小尺寸多次 `blur()` 近似高斯模糊（high: 3次×5px，medium: 1次×3px）
  4. 清空glow层原始纯色，将模糊亮部放大回原尺寸，以 `lighter` 混合叠加（alpha 0.5-0.7）
- **画质分级**: high=全效果，medium=降低模糊次数，low=直接关闭Bloom
- **应用对象**: 发光鱼（glow=true）、金币、炮弹、暴击特效、UI金边

#### 体积光（God Ray）增强（Caustics.js VolumetricFog）
- **重写实现**: 10行梯形切片光束，横向渐变中心亮/边缘透明（软边），纵向随深度衰减
- **微粒条纹**: 双正弦叠加模拟水中微粒明暗条纹
- **光束参数**: 3-5束，位置随机缓慢移动，宽度随深度增加（顶部窄底部宽）
- **昼夜变化**:
  - 白昼: 淡蓝白色(180,220,255)，强度0.15
  - 黄昏: 暖金色(255,180,120)，强度0.12
  - 深夜: 幽蓝色(80,120,180)，强度0.05

#### 深度雾增强
- **API**: `volumetricFog.getFogParams(y, size)` 返回 `{fogAmount, alpha, tint, tintStrength}`
- **雾颜色**: 深海蓝 (r:5, g:25, b:50)
- **分层浓度**: 远景层0.4 > 中景层0.2 > 游戏层（按鱼个体y/size计算）
- **视觉效果**: 远处/深水鱼透明度低(0.6-0.8)、颜色偏蓝、对比度低；近处/浅水鱼颜色真实
- **雾的流动**: 双层正弦水平移动，模拟水流

### 2.5 粒子系统升级

#### 软粒子（Soft Particle）
- 所有粒子默认使用径向渐变（中心实，边缘透明），消除硬边
- 墨滴粒子也改为径向渐变
- 粒子大小调整: 爆炸火焰20-50px，拖尾5-15px

#### 粒子光照
- 非自发光粒子受场景顶部方向光影响: 上方亮，下方暗
- 实现方式: 线性渐变从顶部亮色到底部暗色，亮点上移
- 光照模型: 环境光0.3 + 漫反射0.7（顶部亮度1.0，底部亮度0.3）
- 自发光粒子（gold/coin/flame/scaleSpark/hitFlash）不受光照影响
- 属性: `Particle.isEmissive`（自动覆盖 gold/coin/flame 类型）

#### 新增4种粒子类型
| 类型 | 触发方式 | 视觉效果 | 参数 |
|------|---------|---------|------|
| `scaleSpark`（鱼鳞闪光） | Fish游动时自动随机触发 | 白色/金色小亮点，径向渐变 | size 2-4px, life 0.3-0.5s |
| `waterFlow`（水流粒子） | update中每0.15s定时生成，上限60 | 淡蓝色微光颗粒，缓慢上移 | size 1-3px, life 5-10s |
| `gillBubble`（鱼鳃气泡） | Game中每0.6s随机选鱼吐出 | 半透明小气泡，上升左右摇摆 | size 3-8px, life 1.5-3s |
| `hitFlash`（受击白闪） | 炮弹命中时触发 | 白色闪光，快速放大消失 | size 15-30px, life 0.15-0.3s |

#### 新增发射方法
- `particleSystem.emitScaleSpark(x, y, color)`
- `particleSystem.emitWaterFlow(canvasWidth, canvasHeight)`（自动定时）
- `particleSystem.emitGillBubble(x, y)`
- `particleSystem.emitHitFlash(x, y)`

## 三、性能优化与自动降级

### 画质分级
| 画质 | Bloom | 粒子上限 | 焦散/体积雾 | 模糊次数 |
|------|-------|---------|------------|---------|
| high（高） | 开启 | 800 | 开启 | 3次×5px |
| medium（中） | 降低效果 | 400 | 开启 | 1次×3px |
| low（低） | 关闭 | 150 | 关闭 | - |

### 自动降级机制
- FPS < 25 且当前high → 自动降为medium
- FPS < 18 且当前medium → 自动降为low
- 降级时弹出提示"画质已切换为X"

### 性能保障措施
- OffscreenCanvas鱼鳞纹理只生成一次，静态缓存
- Verlet约束迭代不超过3次
- Bloom模糊使用1/4分辨率缩小实现高效模糊
- 所有新粒子使用对象池复用，避免GC
- 场景元素预生成，运行时仅更新位置/相位

## 七、后续迭代方向（第二阶段展望）

本次为第一阶段Canvas2D深度优化。如需进一步提升至商用级别，可考虑：
1. **WebGL迁移**: 使用WebGL/Three.js实现真正的PBR渲染、法线贴图、实时全局光照
2. **Spine骨骼动画**: 引入Spine/DragonBones专业骨骼动画工具链，20-40根骨骼
3. **3D鱼儿建模**: Maya/3ds Max高精度建模，2000-5000面/条
4. **GPU粒子系统**: ComputeShader实现万级粒子，软粒子深度融合
5. **水面折射**: 屏幕空间折射，水下物体扭曲
6. **动作捕捉**: 真实鱼类运动数据采集驱动动画
