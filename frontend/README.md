# 捕鱼达人·东海龙宫 - 前端H5游戏

## 项目简介

《捕鱼达人·东海龙宫》前端H5游戏，采用原生JavaScript + HTML5 Canvas开发，国风东海龙宫主题，暗调深海墨蓝为主色调，搭配青金琉璃流光、金色龙纹粒子高光。移动端优先，同时兼容PC浏览器。

## 技术特点

- **原生JS + Canvas**: 无框架依赖，性能优异
- **多层Canvas渲染**: 背景层/珊瑚层/鱼群层/炮台层/UI层
- **对象池复用**: 鱼、炮弹、粒子全部池化，避免GC卡顿
- **视差滚动**: 多层独立视差，营造3D伪立体空间感
- **骨骼动画**: 鱼类身体分段摆动，鱼鳍尾鳍独立扇动
- **粒子系统**: 8种粒子特效（金粉/金币/气泡/龙焰/水墨等）
- **PWA支持**: Service Worker离线缓存，可添加到桌面
- **低端机适配**: 自动降级特效，保证流畅运行

## 核心功能

### 游戏玩法
- **金币系统**: 初始赠送10000金币，实时动态展示，击杀获得奖励，金币不足弹出充值
- **炮台系统**: 1-10倍炮切换，倍率越高消耗越高威力越大，3套皮肤（龙纹炮/琉璃炮/鎏金炮）
- **暴击机制**: 随机触发暴击，炮弹变红金烈焰，超大爆炸范围，双倍金币，屏幕红光震动
- **鱼类系统**: 13种鱼（彩色金鱼/小银鱼/灵龟/蝠鲼/黑龙/黄金龙鱼/东海龙王BOSS），全部骨骼动画
- **鱼群AI**: 小鱼成群结队（Boids算法），随机聚集分散，躲避炮弹，大鱼独立巡游
- **捕获判定**: 炮弹碰撞触发，水墨爆炸光效，金珠四散飘落，自动飞入金币账户
- **关卡闯关**: 击杀一定鱼群进入下一关，关卡越难鱼价值越高，结算星级评分

### 视觉特效
- **国风场景**: 珊瑚玉柱/龙宫雕花石柱/流动水墨洋流/升腾珍珠气泡/宫灯柔光
- **3D伪立体**: 多层视差滚动/菲涅尔光影/体积雾/丁达尔光束/鱼体俯仰旋转
- **水体特效**: 水面焦散光斑/炮弹入水波纹/水体扰动/透光折射
- **粒子特效**: 金粉爆炸/金币飞行/珍珠气泡/龙焰冲击波/水墨消散
- **动态光影**: 宫灯柔光呼吸/鱼身高光/UI金边闪烁/全局柔光遮罩
- **昼夜切换**: 白昼透光天蓝/黄昏紫金深海/深夜幽蓝暗光三种场景自动轮换

### UI设计
- **国风大圆角**: 半透磨砂琉璃玻璃面板
- **鎏金发光边框**: 金色龙纹粒子高光
- **青金渐变发光字体**: 文字采用青金渐变
- **按钮微动效**: hover/点击金粉粒子爆炸+缩放
- **云纹龙纹浮雕**: 按钮纹样融入国风元素

### 商用系统
- VIP等级/每日签到/离线收益/幸运转盘/首充双倍
- 周卡月卡/限时折扣/节日礼包
- 装备养成/宠物系统/技能树
- 世界BOSS/公会/好友/排行榜/赛季
- 新手保护/流失召回/广告位预埋

## 快速开始

### 本地运行（需要Node.js）
```bash
cd frontend
node server.js
```
访问 http://localhost:8080

### 其他HTTP服务器
```bash
# Python
python -m http.server 8080

# 或直接用浏览器打开 index.html（部分功能可能受限）
```

## 配置说明

### 游戏配置 `js/config/gameConfig.js`
- 初始金币/钻石/道具数量
- 炮台倍率/消耗/威力
- 暴击率/暴击加成
- 自动开炮间隔
- FPS目标/粒子数量上限

### 鱼类配置 `js/config/fishConfig.js`
- 13种鱼的属性（名称/分值/血量/速度/大小/骨骼段数）
- 鱼群行为参数（聚集/分散/躲避）
- BOSS属性（血量/技能/奖励）

### 关卡配置 `js/config/levelConfig.js`
- 关卡难度/鱼群密度/BOSS出现频率
- 通关条件/星级评分标准

### 后端API配置 `js/api/ApiClient.js`
```javascript
this.baseURL = 'http://localhost:8081/api'; // 后端地址
this.useBackend = false; // 默认本地模式，设为true启用后端
```

## 后端对接

前端已完整封装后端API客户端（`js/api/ApiClient.js`），支持130+接口：
- 认证/玩家/经济/游戏记录
- 签到/邮件/兑换码
- 公会/好友/排行榜/赛季
- 商城/支付充值
- 装备/宠物/成就/任务/VIP
- 世界BOSS/功能开关/通知推送
- 系统配置/数据看板/反作弊

启用后端模式：
```javascript
apiClient.init({ useBackend: true });
```

## 性能优化

- **对象池**: 鱼/炮弹/粒子全部池化，避免频繁创建销毁
- **分层渲染**: 背景静态层缓存，动态层独立渲染
- **视口裁剪**: 屏幕外实体不渲染
- **LOD**: 远处鱼降低骨骼动画精度
- **自动降级**: 低端机关闭粒子/焦散/降低鱼数量
- **资源懒加载**: 首屏资源最小化，进入游戏后预加载
